# OZ Marketplace 0.7.0

- Leaders and officers can create and manage public faction market criers within faction capacity. Creation and dissolution use native confirmation dialogs and have separate faction gender icons.
- Market fees go to the faction account. Wanted-listing payouts continue to use the requester's own Wallet account.
- Existing private and global criers retain their behavior. Active-listing removal safeguards remain in force.
- Build baseline is Java 25 with Rising World PluginAPI 0.9.3.2 and OZ Tools 0.28.0.

Update OZ - Factions to 0.5.0 before enabling faction criers. The Marketplace database receives an additive faction ID column; keep the database during updates. For rollback, remove faction criers and settle open listings before restoring an older plugin or a matching database backup.
